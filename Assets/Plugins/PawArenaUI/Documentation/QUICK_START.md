# Quick Start — Unity

1. The kit is installed at `Assets/Plugins/PawArenaUI` in this project.
2. Unity UI (uGUI) and Input System are already available through Package Manager.
3. Use `Tools > Paw Arena UI > Generate Demo Scene` to rebuild `Assets/_Project/Scenes/UI/PawArenaUIShowcase.unity` and the prefabs in `Assets/_Project/Prefabs/UI/PawArenaUI`.
4. Press Play. Click navigation buttons; use `I`, `G`, `Esc` keys.
5. See `README_VI.md` in ZIP root for layout, import, responsive and 9-slice notes.
